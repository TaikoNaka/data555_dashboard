
# DATA555: Global Cancer Dashboard

## Overview

This project uses the Global Burden of Disease study 2021 (GBD 2021) datasets to examine trends in cancer mortality rates in the world. The study focuses on two perspectives: (1) global temporal trends in cancer mortality from 1990 to 2021, and (2) regional variation in cancer mortality in 2021.

## Dashboard link

[Dashboard] (https://taikonaka.github.io/data555_dashboard/)

## Files inclusded
- index.Rmd – Source code for the dashboard (written in R Markdown).
- index.html – Compiled dashboard, viewable through GitHub Pages.

## Dataset
Global Burden of Disease study 2021 (GBD 2021) datasets, provided by the Institute for Health Metrics and Evaluation (IHME).

## Why This Project Matters
By visualizing mortality rates by cancer type over time and across different regions, this analysis aims to assess long-term trends in mortality rates across major cancer types globally, and highlight the geographical disparities in the global cancer burden. This information generates insights that can inform global and regional cancer control strategies.
